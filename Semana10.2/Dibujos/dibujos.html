Semana 10.2

Programación Estructurada

1. Comprender los enlaces

Una lista enlazada conecta nodos mediante referencias. cabeza referencia al primer nodo; None indica ausencia de nodo. El último nodo tiene siguiente = None.

Los diccionarios representan nodos y sus valores guardan referencias a otros diccionarios. Python administra la memoria: aquí no manipulamos direcciones manualmente. Una list de Python usa un arreglo dinámico de referencias; no es esta estructura enlazada. Aquí no hay acceso directo por índice: hay que recorrer los enlaces.


2. Crear el nodo

Crea el archivo lista_enlazada.py. Agrega esta función. Cada llamada produce un nodo independiente. 

def crear_nodo(dato):
      return {"dato": dato, "siguiente": None}


3. Insertar al inicio

Primero conecta el nuevo nodo con la cabeza anterior; después devuelve la nueva cabeza. El orden evita perder el acceso al resto de la lista. 

def insertar_inicio(cabeza, dato):
        nuevo = crear_nodo(dato)
        nuevo["siguiente"] = cabeza
        return nuevo


4. Insertar al final

Si está vacía, el nuevo nodo pasa a ser la cabeza. Si tiene elementos, avanza hasta el último nodo y conecta el nuevo. 

def insertar_final(cabeza, dato):
      nuevo = crear_nodo(dato)
      if cabeza is None:
          return nuevo
      actual = cabeza
      while actual["siguiente"] is not None:
          actual = actual["siguiente"]
      actual["siguiente"] = nuevo
      return cabeza


5. Recorrer y mostrar

La variable auxiliar actual avanza sin cambiar la cabeza. En una lista vacía se imprime únicamente None.


6. Buscar un turno

Recorre desde la posición 0. Devuelve la primera posición encontrada o -1 si el nombre no existe.


7. Eliminar un turno

Distingue lista vacía, eliminación de la cabeza y eliminación de otro nodo. Devuelve una tupla: nueva cabeza y confirmación. Reenlazar el anterior con el siguiente excluye al nodo eliminado.
